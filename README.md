Forward Window v4 ranks protocols that record no token by cap at launch × conditional 24-month scenario odds. TVL, relative seven-day growth and time since listing each have visible effects. Repeated 5×5 folds and listing-date walk-forward tests audit cap error and current token status. The farm-first board shows positive P25 net, estimated net per active hour, and seven-step budgets with chain fees, exit conditions and a 4% annual capital charge.

Run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json` with Node 22.18 or later, then open `out/dashboard/index.html` directly from disk.
